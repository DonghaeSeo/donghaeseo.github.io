# Website assets

Profile portrait and email-free public curriculum vitae for Donghae Seo's academic website.

Institutional emblems are copied unmodified from the official KAIST and POSTECH
identity resources:

- KAIST: https://www.kaist.ac.kr/en/html/kaist/011901.html
- POSTECH: https://www.postech.ac.kr/kor/university-introduction/emblem.do

STIX Two Text WOFF2 files come from the official STIX v2.0.2 archive:
https://github.com/stipub/stixfonts/tree/master/archive/STIXv2.0.2/WOFF2
The SIL Open Font License is included at `fonts/OFL.txt`.
